jog shell install — add the git alias and preexec hook to your shell

usage:
  jog shell install [--no-alias|--no-preexec] [<shell>…]

Appends two marked lines to the shell's rc file, creating the file if
needed: the alias — `alias git='jog git'` (PowerShell: a git function)
— and the preexec hook — one line calling `jog shell-hook` before every
interactive command. With no names it targets your login shell ($SHELL;
PowerShell on Windows); name shells to wire others, rc file or not. A
line you added by hand is recognized and left alone.

--no-alias installs only the preexec hook; --no-preexec only the alias.
Both lines guard on jog existing, so a removed binary never breaks your
prompt.

Takes effect in new shells; source the rc file to get it in this one.
The bash line uses PS0 (bash 4.4+) — older bash ignores it harmlessly,
as does `shopt -u promptvars`. Re-sourcing an rc file registers the
hook twice; the second fire is a no-op. The cost is one no-op jog run
per command inside a repo, near-zero outside.

supported: bash, zsh, fish, powershell (alias only — no preexec mechanism)
