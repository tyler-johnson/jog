jog shell — the git alias and preexec hook in your shell

usage:
  jog shell <command> [<args>]

commands:
  install    add the alias and preexec hook to a shell's rc file
  uninstall  remove jog's lines from rc files
  list       every supported shell and what is installed

Two lines cover your interactive work, both installed by default:

  alias    `alias git='jog git'` — snapshots before every git command
           you type
  preexec  one line calling `jog shell-hook` before each command —
           snapshots before everything else too: `rm`, `sed -i`,
           `make clean` (bash 4.4+, zsh, fish; PowerShell has no
           preexec mechanism and gets the alias only)

On a git command both fire; the second snapshot is a no-op. Scripts,
IDEs, and CI are untouched: they resolve git on PATH and get real git,
and rc files are interactive-only.

"jog help shell <command>" (or jog shell <command> --help) has the details.
