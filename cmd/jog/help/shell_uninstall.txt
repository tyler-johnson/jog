jog shell uninstall — remove the git alias and preexec hook

usage:
  jog shell uninstall [--no-alias|--no-preexec] [<shell>…]

Removes exactly the marked lines install appended, nothing else. With
no names it sweeps every rc file carrying jog's lines; a line you wrote
by hand is never touched — a note says so, and removing it is yours to
do.

--no-alias removes only the preexec hook; --no-preexec only the alias —
so `jog shell uninstall --no-alias` turns off before-every-command
snapshots while the git alias keeps working.
